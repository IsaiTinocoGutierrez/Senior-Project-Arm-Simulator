# Robot Chess Project

A robotic chess system using:

- Python
- URSim / Universal Robots
- Stockfish
- Tkinter UI
- python-chess

## Features

- Play chess against Stockfish
- Robot arm executes moves
- Clickable chess board UI
- Captured pieces tracking
- Move logging
- Reset game support

## Project Structure

```text
ui/        -> user interface
services/  -> chess logic
robot/     -> robot communication and movement
shared/    -> shared constants
```

## Run

```bash
python main.py
```
